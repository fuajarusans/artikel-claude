# Cara Membangun Program Citizen Developer di Perusahaan dengan Low-Code Platform

## Hook hypothesis

Banyak perusahaan Indonesia sudah beli lisensi platform low-code — tapi enam bulan kemudian platformnya tidak dipakai. Bukan karena teknologinya salah, tapi karena tidak ada program yang mendampingi pengguna bisnis menjadi *citizen developer* yang produktif. Artikel ini memberikan kerangka kerja praktis (bukan vendor pitch): bagaimana IT manager dan CIO memulai, menstruktur, dan mengukur keberhasilan program citizen developer. Soltius relevan karena sebagai mitra implementasi SAP Build di BTP, mereka sering membantu klien melewati fase "beli tapi tidak dipakai" ini.
