# SAP Build di SAP BTP: Platform Low-Code yang Dirancang untuk Ekosistem ERP

## Hook hypothesis

Banyak perusahaan Indonesia yang sudah jalan di SAP S/4HANA atau SAP Business One menghadapi masalah yang sama: ada kebutuhan aplikasi baru yang tidak bisa ditangani modul standar — tapi membangun secara custom tradisional mahal, lama, dan berisiko merusak stabilitas sistem inti. SAP Build di atas SAP BTP hadir sebagai jawaban yang sering belum diketahui tim IT. Artikel ini relevan langsung bagi pengguna SAP aktif dan tim IT yang mau memperluas kemampuan ERP tanpa proyek besar. Soltius relevan karena Digital Platform solution mereka secara langsung mencakup implementasi SAP Build dan BTP.

## SAP / partner tech to teach (from product_matrix.md)

- **SAP Build Apps** (sebelumnya AppGyver): visual low-code app builder, drag-and-drop, mobile/web, pre-built connectors ke SAP S/4HANA.
- **SAP Build Process Automation**: RPA + workflow automation + decision tables; menggabungkan SAP Intelligent RPA dan SAP Workflow Management.
- **SAP Build Work Zone**: employee experience portal / digital workspace — menggabungkan SAP Work Zone dan SAP Launchpad.
- **SAP BTP**: Business Technology Platform — foundation cloud; integration, extension, data management, AI layer.
- **Clean core extensibility Level A**: SAP Build adalah tool resmi untuk side-by-side extension sesuai clean core model — tidak memodifikasi core S/4HANA.
- **Joule Studio 2.0**: AI-assisted low-code environment untuk business analyst/citizen developer (rolling out Juni 2026) — **researcher harus konfirmasi scope dan release date resmi**.
- **ABAP Cloud**: on-stack extensibility yang masih upgrade-safe — berbeda dari classic ABAP modifications; researcher verifikasi perbedaan dengan SAP Build.
