## SAP / partner tech to teach (from product_matrix.md)

- **SAP Build Apps**: bangun aplikasi mobile/web untuk shop-floor (form QC, request maintenance, approval PO) — native SAP connector.
- **SAP Build Process Automation**: otomasi workflow cross-system (3-way match, approval routing, notifikasi).
- **SAP BTP**: integration layer yang menghubungkan SAP Build dengan S/4HANA PP, MM, PM modules.
- **SAP Digital Manufacturing (Cloud)**: ini BUKAN low-code — ini sistem MES full-featured. Artikel harus membedakan keduanya dengan jelas agar tidak menyesatkan. Researcher verifikasi scope SAP Digital Manufacturing.
- **SAP Production Planning (PP)**: modul S/4HANA untuk produksi — low-code di atasnya untuk reporting/workflow, bukan untuk mengubah PP itu sendiri.
- **Automotive case study**: "global automotive manufacturer, 20% reduction in unplanned downtime" via SAP Build Process Automation (GigaOm/SAP, 2025) — researcher konfirmasi sumber.
