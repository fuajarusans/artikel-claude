# Article notes

## Angle summary
Artikel ini mengisi celah penting sebelum keputusan migrasi dibuat: bagaimana menilai kesiapan organisasi secara objektif. Distinct angle-nya adalah panduan self-assessment yang bisa dilakukan pembaca sendiri — bukan menunggu vendor melakukan assessment berbayar — dengan lima dimensi kesiapan (teknis, proses bisnis, data, people/change, anggaran). Artikel menempatkan SAP Readiness Check dan SAP Signavio Process Insights sebagai tool yang membantu objektifikasi assessment, sehingga pembaca tahu persis apa yang harus disiapkan sebelum memulai proyek migrasi.

## Subtopics covered
- Lima dimensi kesiapan migrasi ERP: teknis, proses bisnis, data, people/change, anggaran
- SAP Readiness Check: apa yang dianalisis dan outputnya
- SAP Signavio Process Insights: pemetaan proses as-is untuk fit-gap
- Custom code legacy: inventarisasi dan strategi remediasi
- Data quality assessment sebelum migrasi
- Change readiness: mengukur kesiapan organisasi dan SDM
- TCO baseline: memahami biaya sebelum membandingkan dengan cloud
- Discovery phase: struktur dan output yang diharapkan
